# 管理员采集与积分更新

更新：2026-10-03。需要迁移 `0006_collection_management` 和匹配的新 web/worker。管理入口 `/admin/collection`，平台登录入口 `/admin/connections`。

## 使用

默认只启用 CF；CF 不需要管理员外站登录，成员须有生效绑定。加入 QOJ/洛谷前完成对应登录或身份核验。未启用、未登录、没有生效绑定的平台显示跳过原因，不阻塞其他平台。

日期支持滚动近 7/30 天和自定义日期，默认近 30 天；北京时间首尾都包含，自定义最多 366 天。保存平台或日期后立即更新；总采集开关暂停时保存设置，恢复后执行。已有区间外事实保留，首次 AC 在全部已采集有效历史中求最早，再过滤区间。历史未完整时积分暂定。

“立即更新积分”执行一次增量同步。自动同步默认关闭，周期默认 360 分钟，可设置 1–10080 分钟。页面每 5 秒刷新任务和积分预览；提交数含分页重叠，不等于首次 AC 题数。

关闭平台保留事实，但该平台退出计分。登录失效只暂停采集，已启用平台的历史积分保留。查询默认使用管理员日期及平台；已有显式日期查询、管理员单次指定区间继续可用，平台参数不能绕过管理员关闭的平台。

## 存储、调度与限速

`collection_settings` 保存平台、自动开关、周期、日期和版本；`collection_platform_state` 保存平台采集版本；绑定保存到期、失败暂停和待更新状态。`SYNC_ENABLED` 只初始化缺失的自动开关，迁移重复执行不会覆盖设置。

worker 启动时及每分钟扫描到期目标。手动、定时、绑定成功和设置变更共用事务投递入口；同一绑定的活动验证/同步合并。正常完成后下次到期为完成时间加周期；重启不补发积压周期。分批续跑保留独立 job ID 和提交游标。

临时错误沿用最多 3 次自动重试，耗尽后停止周期调度，须管理员重试。鉴权失败等待新的核验，解析变化等待修复后手动重试；其他平台继续运行。

单次 HTTP 随机间隔与同步周期独立：CF 默认 2000–3000 ms，QOJ/洛谷默认 3000–5000 ms；最低分别为 2000/1000 ms，最高 60000 ms。沿用共享数据库限速、每平台并发 1，修改间隔不清除已有冷却或租约。获得配额后再次检查采集权限/版本；平台登录及纯身份核验独立可用。

## API

所有接口需要管理员会话，写请求需要本站 Origin 和 `X-CSRF-Token`，响应禁止缓存。

| 接口 | 行为 |
| --- | --- |
| `GET /api/admin/collection-settings` | 设置及平台绑定数、事实数量、最近成功、下次到期、暂停数和跳过原因 |
| `PUT /api/admin/collection-settings` | `{platforms,autoSyncEnabled,syncIntervalMinutes,scoreRange,version}`，返回 `{settings,items}`；版本冲突 409 |
| `POST /api/admin/sync` | `{accountIds?,platforms?,mode?,from?,to?}`；省略平台/日期时使用设置，返回目标任务、合并、跳过或错误 |
| `GET /api/admin/sync-jobs` | `platform/status/limit/cursor`，默认 20、最多 100，返回 `{items,nextCursor}` |
| `GET /api/admin/sync-jobs/:id` | 业务和队列状态、来源、时间、页数、区间及完整性 |
| `POST /api/admin/sync-jobs/:id/retry` | 从事实对应游标续跑；仍须校验平台与采集版本 |
| `POST /api/admin/collection-reset` | `{platforms,version,requestId}`，requestId 为 UUID；202 返回清理摘要及回填任务 |

日期为 `{kind:"rolling",days:7|30}` 或 `{kind:"fixed",from:"YYYY-MM-DD",to:"YYYY-MM-DD"}`。平台 ID 为 `codeforces/luogu/qoj`，设置可使用空集合。版本冲突、平台关闭、采集暂停、未登录或幂等标识冲突返回 409。

## 清空后重爬

页面展示所选平台、清理数量和区间，确认后执行。所有选定平台必须已启用、登录就绪且有生效绑定，否则不清理。

事务内提升平台采集版本、取消旧同步队列任务、删除所选平台提交/归属/题目及游标，再投递当前区间回填。保留用户、身份/绑定、本站会话、平台登录、策略、设置、运行历史和审计；不删库或数据卷。

单页提交与清理使用共享/独占数据库锁，旧任务晚返回不能写回，旧版本检查点不能复用。同一管理员重复 requestId 返回原结果，不再次删除；不同参数复用标识返回冲突。失败保留本次已成功提交页，可重试续跑。

## 验证与部署

`pnpm personal:verify` 创建随机命名的独立测试库，验证个人事实、登录、配置、并发调度、平台跳过、失败暂停、局部清理、旧任务/检查点失效、幂等重爬及会话保留，不访问真实平台。成功删除测试库，失败保留库名诊断。

在含 Chromium 的对应应用镜像运行 `pnpm personal:verify --http`，额外启动回环端口 3001 的测试 Web，验证管理员/成员权限、Origin/CSRF、分页、配置冲突、页面操作及桌面/手机布局；截图输出 `/tmp/collection-probe`。该验证不启动正式采集 worker。

发布前备份、暂停采集并确认无活动任务；迁移后部署匹配的 web/worker，保留 PostgreSQL 卷和 QOJ 浏览器会话。既有专用浏览器使用当前运行手册的 worker 原位更新流程，不通过重建浏览器验证管理页面。
