# 平台能力观察（历史归档）

从产品设计附录迁出，保留早期页面观察。当前实现和真实读取验收请查看[文档索引](../README.md)。

## 9. 平台数据获取实测附录

测试日期：2026-10-01。本文记录 Codeforces、QOJ、洛谷的登录途径，以及做题、比赛、组队和 VP 数据的读取方式。`{handle}`、`{uid}`、`{id}` 等为占位符。文中区分官方 API、登录后网页和未完成验证的接口。

### 9.1 Codeforces

**登录：**公开做题记录无需登录。API 基地址为 `https://codeforces.com/api/`，响应为 JSON；成功时格式为 `{ "status": "OK", "result": ... }`。官方限制为每 2 秒最多请求一次。需要访问有权限限制的数据时，才需在 [API 设置页](https://codeforces.com/settings/api)申请 key，并按[官方签名规则](https://codeforces.com/apiHelp)请求。

| 用途 | GET 地址 | 关键返回字段 |
| --- | --- | --- |
| 用户提交 | `https://codeforces.com/api/user.status?handle={handle}&from=1&count=100` | `result[]` 中的 `id`、`creationTimeSeconds`、`verdict`、`problem`、`author` |
| 用户评级比赛 | `https://codeforces.com/api/user.rating?handle={handle}` | 比赛 ID、名次、更新前后 rating |
| 比赛提交 | `https://codeforces.com/api/contest.status?contestId={id}&handle={handle}&from=1&count=100` | 该比赛的提交列表 |
| 公开常规赛榜单 | `https://codeforces.com/api/contest.standings?contestId={id}` | 比赛、题目及正式榜单行 |

`user.status` 已实测返回数据。通过题目可用 `verdict === "OK"` 判断。其 `author.participantType === "VIRTUAL"` 表示 VP；`author.members[]`、`teamId`、`teamName` 提供组队信息。`user.rating` 只覆盖评级比赛，不能代替完整参赛或 VP 记录。字段定义见[官方对象文档](https://codeforces.com/apiHelp/objects)，参数见[官方方法文档](https://codeforces.com/apiHelp/methods)。

**榜单限制：**公开常规赛的匿名 `contest.standings` 请求目前只能携带 `contestId`，返回正式榜单；Gym 和 Mashup 的榜单需要有相应访问权限的签名请求。不要给公开常规赛的这个地址追加 `handles`、`showUnofficial` 等参数来查询 VP。[官方说明](https://codeforces.com/apiHelp/methods#contest.standings)

### 9.2 QOJ

**登录流程（已实测成功）：**打开[登录页](https://qoj.ac/login) → 输入用户名、密码 → 点击 Submit。此次登录没有出现验证码。登录后使用同一浏览器会话访问下列页面。**没有验证登录表单的 POST 地址、请求体，也没有找到稳定的公开 JSON API 文档**；下表地址均按网页地址使用。

| 用途 | 网页地址 | 已实测可读内容 |
| --- | --- | --- |
| 用户主页 | `https://qoj.ac/user/profile/{handle}` | Accepted problems、Tried problems、Virtual Participations；VP 项包含比赛链接及开始时间 |
| 用户提交 | `https://qoj.ac/submissions?submitter={handle}&page={n}` | 提交 ID、题目、结果、耗时、内存、语言、文件大小、提交时间；`page` 翻页 |
| 比赛提交 | `https://qoj.ac/contest/{id}/submissions` | 比赛中的提交记录及翻页 |
| 比赛榜单 | `https://qoj.ac/contest/{id}/standings` | 名次、得分、罚时等榜单信息 |
| 队伍主页 | `https://qoj.ac/user/profile/{teamHandle}` | Team Members 区域中的成员账号链接，以及该队伍的 VP 记录 |

这些地址在登录后已打开验证；未登录访问所测的用户主页、提交页和榜单页会跳转登录。用户主页中的通过题目是 `/problem/{id}` 链接，队伍成员是 `/user/profile/{handle}` 链接。QOJ 的[比赛系统说明](https://qoj.ac/blog/ucupannouncements/blog/701)也介绍了虚拟参赛和队伍账号。

**VP 数据边界：**主页能确认 VP 比赛及开始时间，比赛提交页能查提交。本次所查的一个 VP 页面提示参赛者需点击 “Finish” 更新榜单；因此**尚未确认未完成 VP 的最终名次可被读取**。

### 9.3 洛谷

**登录流程（已实测成功）：**打开[登录页](https://www.luogu.com.cn/auth/login) → 输入账号并点击“下一步” → 输入密码和图片验证码 → 登录。此次验证码由用户填写。浏览器登录后，提交记录页可访问；未登录打开该页会跳转登录。

第三方[非官方身份验证文档](https://github.com/0f-0b/luogu-api-docs/blob/main/auth.md)列出 `GET /lg4/captcha` 和 `POST /do-auth/password`。**本次只验证了网页登录流程，没有抓取并验证这两个请求的完整参数、响应和 CSRF 要求**，所以不能把它们写成已确认可直接调用的登录接口。

| 用途 | 网页地址 | 已实测数据 |
| --- | --- | --- |
| 用户通过及尝试题目 | `https://www.luogu.com.cn/user/{uid}/practice` | 页面内 `script#lentille-context` 的 `data.passed[]`、`data.submitted[]` |
| 用户原始提交 | `https://www.luogu.com.cn/record/list?user={uid}&page={n}` | 同一脚本内的 `data.records.count`、`perPage`、`result[]` |
| 单条提交详情 | `https://www.luogu.com.cn/record/{id}` | 在列表中观察到此链接；详情字段未实测 |

`practice` 页的题目项可读到 `pid`、名称、难度等。这里的 `data.submitted[]` 指页面显示的**尝试但未通过题目**，不是逐条原始提交。用户若开启隐私保护，该页可能不给出题目列表。[相关非官方文档](https://github.com/0f-0b/luogu-api-docs/blob/main/users.md)

`record/list` 已实测可在登录后按 `user` 查询其他用户、按 `page` 翻页。此次页面显示每页 20 条；单条记录含 `id`、`status`、`score`、`submitTime`、`problem`、`user`，比赛提交还可能含 `contest` 对象。实测通过记录的 `status` 为 `12`。**这是 HTML 页面内嵌的 JSON，不是本次已验证的独立 JSON 响应接口。**[相关非官方文档](https://github.com/0f-0b/luogu-api-docs/blob/main/records.md)

**比赛、团队和 VP：**非官方文档还列出 `GET /api/user/joinedContests?page={n}`、`GET /team/{id}/member` 等路径，分别见[比赛文档](https://github.com/0f-0b/luogu-api-docs/blob/main/contests.md)和[团队文档](https://github.com/0f-0b/luogu-api-docs/blob/main/teams.md)。本次**没有成功实测这些路径**。已读取的提交记录可通过 `contest` 关联比赛，但没有验证出能可靠区分 VP 的字段，也没有验证比赛组队成员字段。

### 9.4 获取能力汇总

| 数据 | Codeforces | QOJ | 洛谷 |
| --- | --- | --- | --- |
| 通过题目、逐条提交 | 官方 JSON API，已验证 | 登录后网页，已验证 | 登录后网页内嵌 JSON，已验证 |
| VP 参与 | `author.participantType`，已确认 | 用户主页列表，已确认 | 未确认可靠字段 |
| 组队成员 | `author.members[]`，已确认 | 队伍主页 Team Members，已确认 | 有非官方路径，未实测 |
| VP 最终名次 | 公开常规赛 API 不提供 VP 榜 | 未完成的 VP 未确认 | 未确认 |

账号密码、会话 Cookie、验证码和令牌均未写入本文档。
